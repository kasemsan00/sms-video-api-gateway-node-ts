## ขั้นตอนการดำเนินการสำหรับคนขับรถ

### ขั้นตอนการดำเนินการ

1. รับลิ้งค์ SMS จากเว็บหลังบ้าน
2. ส่ง SMS ไปยังเบอร์มือถือของคนขับ
3. ถ้าแอพ Mobile App ติดตั้งเรียบร้อยแล้วจะเปิดแอพอัตโนมัติพร้อมกับส่ง `task id` ไปให้แอพ

### โครงสร้าง RestAPI

เมื่อคนขับเข้าถึงลิ้งค์ SMS และ Mobile App เรียกข้อมูลงานจาก API จะได้รับข้อมูลดังนี้

### ประเภทสถานะ

- `open`: งานเปิด
- `start`: เริ่มงาน
- `arrive`: รับผู้ป่วยเรียบร้อย
- `cancel`: ยกเลิกงาน
- `complete`: เสร็จสมบูรณ์

### API Endpoint

- [ดึงข้อมูลงาน](car/task/get.md) : `GET /car/task?id=1234`
- [อัพเดทข้อมูลงาน](car/task/put.md) : `PUT /car/task`
